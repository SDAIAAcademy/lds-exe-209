## التشغيل والتحقق

لا يحتاج أي مختبر حسابًا أو مفتاحًا أو تثبيتًا: البيئة المعزولة صفحة واحدة تعمل في المتصفح دون اتصال، والملفات تُفتح في المتصفح أو جدول بيانات. للتحقق (Node 20 أو أحدث، دون حزم):

```
node labs/solutions/check.mjs
node labs/solutions/check.mjs --log <سجل الفريق> --facts <ورقة الحقائق>
```

الأول يعيد بناء الملفات ويقارنها بالموجود، ويعيد حساب أرقام المختبر 1.1 من الملفات، ويفحص السجل المرجعي بالإجراء (من يقرر، والفصل بين المهام، والمهل)، ويتحقق من صفحة البيئة المعزولة. الثاني يفحص سجل فريق وورقة حقائق، ولا يتوقف على قالب فارغ. لإعادة كتابة الملفات بعد تعديل الحالة في `_tools/case.mjs`:

```
node labs/_tools/build_files.mjs
```

## ما لم يُشغَّل على نموذج

لم يُشغَّل أي مختبر على نموذج لغوي عند البناء. «مِنهال» و«مُقتَني» في البيئة المعزولة برنامج مكتوب السلوك يقوم مقام النموذج المستضاف، لتكون النتائج واحدة لكل من في القاعة، ونتائج إعادة الاختبار في `files/retest_results.csv` من هذا البرنامج، لا من نموذج. البيانات كلها اصطناعية، وأرقام الهويات والجوالات مقنَّعة في الملفات.
